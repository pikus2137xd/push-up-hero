# TRENING HERO 4.0

Osiem ćwiczeń, lobby i osiem osobnych bossów z własnymi historiami. PWA na iPhone i Windows.

Gra: https://pikus2137xd.github.io/push-up-hero/

Domyślny tryb „Czułe — krótsze ruchy” wymaga mniejszego zakresu; pozostał wybór „Dokładne”. Pompki od przodu: kalibracja góry, wspólny pionowy ruch głowy i barków, domyślny próg 14% zamiast 24% szerokości barków. Suwak 8–40%: mniej oznacza czulej. Alternatywny tryb z boku mierzy łokieć. Deska nalicza czas widocznego podporu i zwiększa obrażenia w ciągłej serii. Bieżnia to ręczny timer oparty na prędkości wpisanej suwakiem, bez połączenia z urządzeniem. Pozostałe tryby: brzuszki, ciężarki, przysiady, pajacyki i wysokie kolana.

Każda misja ma własne HP, wygląd bossa, historię początkową i zakończenie. „Resetuj bossa” odnawia tylko daną misję, zachowując wyniki i monety. Nagrody za pierwsze zwycięstwo nie duplikują się po resecie. Poprzednie wyniki są migrowane.

Włączanie lokalnie: Python 3, START-WINDOWS.cmd. Hosting: statyczne pliki HTTPS, np. GitHub Pages. Na iPhonie otwórz adres w Safari i dodaj do ekranu początkowego. Szczegóły w INSTRUKCJA.html.

Eksperymentalne rozpoznawanie ruchów, bez testów fizycznej kamery na iPhonie. Nie ocenia techniki i nie mierzy ciężaru hantli ani prędkości pasa bieżni. Model kamery wymaga internetu. Wideo jest analizowane na urządzeniu. Wyniki zapisują się lokalnie.
